Tracks the highest-dollar live events on the Kalshi demo exchange across five focus topics — gas prices, elections, culture, crypto and golf — until each market resolves yes or no. Two scrolling chat panes record observed moves of at least $0.10 into a live alert, and every number on the site links to the official endpoint or document it came from.

Executive summary

What this is. A static, dependency-free dashboard for Kalshi's official demo Trade API. The recommended REST root is https://external-api.demo.kalshi.co/trade-api/v2 (also supported: https://demo-api.kalshi.co/trade-api/v2); the WebSocket root is wss://external-api-ws.demo.kalshi.co/trade-api/ws/v2 (also supported: wss://demo-api.kalshi.co/trade-api/ws/v2). These match the endpoint table in Test In The Demo Environment and API Environments and Endpoints exactly.

Verified facts this site is built on.

  • Public market data — series, events, markets, order books and candlesticks — is reachable without authentication (Quick Start: Market Data). Only those endpoints are used for the live feed.
  • Balances, positions and orders require request signing (KALSHI-ACCESS-KEY, -TIMESTAMP, -SIGNATURE; timestamp + METHOD + path signed with RSA-PSS/SHA-256 or Ed25519) — Quick Start: Authenticated Requests. A static page therefore cannot read your portfolio or place an order, because the browser is not allowed to send those signed headers (measured preflight, F-66). The Demo account page shows only what a GitHub Actions job wrote to data/account.json; no key ever reaches your browser, and nothing here asks you to paste one.
  • Binary markets resolve yes/no (other markets can have scalar results); the winning binary side is paid $1.00 per contract (Market Settlement, Market Lifecycle). The tracker follows sampled/alerted markets toward finalization. REST sampling can miss moves between polls; this is not a guaranteed tick feed.
  • The demo environment uses mock funds and separate credentials, and Kalshi warns that demo prices may not reflect real markets — demo_env. Nothing on this site is a trading recommendation.

At the verified snapshot (2026-11-27 14:10:33 UTC): the capture found 2477 open markets across the five topics and 122 tracked series (top 30 per topic), using 185 documented endpoints. The highest-dollar focus-topic rows are listed below and carry their own source links.

What is deliberately blank or flagged. Anything the API did not return is left blank and published on the Flagged for Review page with the reason. The site never fills a gap with a guess.

How to use this site

Watch and decide

  1. Live dashboard — two scrolling chats: every move ≥ $0.10, and only the moves the ROI model likes.
  2. Live alerts console — the same two chats fed by the background engine, so the record keeps running when no browser is open.
  3. Markets — the full tracked list, filterable by topic and by open/resolved, with each market's result.
  4. Topic pages — series, open markets, liquidity and resolved events for one topic at a time.
  5. Market detail — price chart (30 s → 24 h), order-book ladder, settlement rules, paper trade.

Trade and verify

  1. Portfolio — the simulated portfolio, the auto-trader and the equity curve.
  2. Analysis — trades categorised by strategy and topic so you can build a strategy from the results.
  3. Strategies — the exact rule behind every strategy and behind the ROI score.
  4. Swing catalysts — every ≥ $0.10 move with its official event link and the settlement sources the API names, plus clearly-labelled discovery links for a possible cause.
  5. Sources · Flagged for review · Questions — provenance and open items.
