Executive Summary — KalshiDash1

Live dashboard for Kalshi demo event contracts. Focus: gas prices, elections, culture, crypto, golf.

What this dashboard does

  • Tracks the highest dollar-amount live events on Kalshi until they resolve (resolved Yes / No).
  • Tracks portfolio performance using the Kalshi demo account (mock funds; demo credentials are not shared with production).
  • Analyzes trades, categorizes them by type, and surfaces trade strategies by trade type.
  • Renders live-interactive price graphs: X axis = time (seconds / minutes / hours), Y axis = current contract price.
  • Shows current liquidity and how many contracts are available at a given price.
  • Provides a suggestions section for reviewing improvement paths before implementing changes.
  • Provides a Q&A section listing questions/information/answers that must be addressed before decisions.

How to read the tables

  • Ticker — Kalshi market/event ticker.
  • Yes / No price — current contract price in cents (¢).
  • Resolved — YES / NO once the event settles; "Unresolved" while live.
  • Liquidity — volume / contracts available at a given price (from the order book).
  • Source link — every row links to an official Kalshi docs page or the demo site. Blank/unverified values are flagged and never inferred.
