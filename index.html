KalshiDash1

A clean, simple dashboard for tracking live Kalshi demo events — focused on gas prices, elections, culture, crypto, and golf — with live contract-price graphs, orderbook liquidity, portfolio performance tracking, trade execution structure, and a decision-making suggestions section.

Open Live Dashboard View Flagged for Review

Focus categories

Gas prices · Elections · Culture · Crypto · Golf. Each has its own subpage with a findings table and source links.

Live price graph

X axis = time, Y axis = contract price. Choose the graph length (seconds / minutes / hours). Shows current liquidity and contracts available at each price.

Portfolio & trades

Track demo-account portfolio performance, categorize trades, and build strategies by trade type. Authenticated endpoints require your own demo API credentials.

Suggestions & questions

A suggestions section for site/decision improvements plus a pre-decision questions/information/answers list with missing-info discovery steps.

Important verification note What is — and isn't — confirmed

  • The demo API endpoints above are verified against the official Kalshi documentation (source linked).
  • Public market-data endpoints (/markets, /orderbook, /candlesticks) need no authentication and are called live by the browser in the dashboard.
  • Demo environment contents: at the time of review the demo environment listed sports markets (college football/basketball, NFL). Markets for gas prices, elections, culture, crypto, and golf were not confirmed in the demo environment. Those categories are flagged unverified on their subpages with the official discovery method as the source. No values were inferred or filled in.
  • Authenticated endpoints (portfolio balance, order placement/execution) require a demo API key + Ed25519 private-key signature. No credentials were provided or requested, so portfolio/trade execution is shown as a documented structure only and is flagged.
Every table row on this site carries a source link to an official Kalshi site. If a value cannot be confirmed from an official source, it is left blank and flagged unverified. See Flagged for Review.
