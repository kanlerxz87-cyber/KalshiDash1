Kalshi Demo Dashboard

Tracks the highest-dollar live events on the Kalshi demo exchange across five focus topics — gas prices, elections, culture, crypto and golf — until each market resolves yes or no. Every number links to the official endpoint or documentation page it came from. Portfolio and trade execution are simulated in-browser (real demo-account sync needs the account holder's API keys — see Questions & Gaps).

Data source: probing the official demo API (external-api.demo.kalshi.co)… If your browser cannot reach it (CORS/network), the site falls back to a verified snapshot captured 2026-11-20 and says so here.

Executive summary

What this is. A static, dependency-free dashboard for Kalshi's official demo Trade API (recommended REST root https://external-api.demo.kalshi.co/trade-api/v2, also-supported https://demo-api.kalshi.co/trade-api/v2; WebSocket wss://external-api-ws.demo.kalshi.co/trade-api/ws/v2). Endpoint URLs in your brief match the official documentation exactly (API Environments and Endpoints, Test In The Demo Environment).

Key verified facts.

  • Public market data (series, events, markets, orderbook, candlesticks, trades) is reachable without authentication (Quick Start: Market Data) — the dashboard uses only these.
  • Orders, balances and positions require API-key request signing (KALSHI-ACCESS-KEY / -SIGNATURE / -TIMESTAMP headers, RSA-PSS or Ed25519) — docs. Real order placement is POST /portfolio/events/orders (V2); the legacy /portfolio/orders writes return 410 Gone — Create Order (V2).
  • Markets resolve with result = "yes" or "no"; winning side receives $1 per contract (Get Market schema, Market Settlement). The Events tracker follows each market from live → resolved.
  • Demo environment uses mock funds and separate credentials, and Kalshi warns demo prices may not reflect real markets — demo_env.md.

Highest-dollar focus-topic activity at the verified snapshot (2026-11-20 11:10 UTC): the elections market KXELECTIONEMERGENCY-27JAN01 led the focus topics with 7,475.30 contracts traded and equal open interest (~$7,475 notional at $1/contract), followed by the demo hourly BTC market KXDEMOFUTHOURLY-26NOV20H12-UP with 1,175.00 contracts. Gas, golf and culture had no open markets at that moment (their series trade on daily/tournament schedules) — all rows and empty-result probes are recorded with source links in Sources.

What is deliberately blank / flagged. Real demo-account portfolio numbers (need credentials), anything the API did not return, and the events-endpoint category-filter quirk (F-01). See Flagged for Review — nothing on this site was inferred or filled in.

How to use this site

Track & trade (simulated)

  1. Live Events — pick a topic tab, sort by dollar volume, follow each market to resolution (yes/no).
  2. Market Detail — price chart (seconds/minutes/hours windows), full orderbook ladder (contracts available at each price), rules and settlement sources.
  3. Portfolio — place simulated trades against live prices; P&L, win rate, exposure and equity curve.
  4. Trade Analysis — categorize trades by topic and strategy; compare performance; strategy definitions.

Decide & verify

  1. Suggestions — improvement proposals with impact/effort; review and approve/reject before implementing.
  2. Questions & Gaps — what we know, what we don't, and how to find out — before any decision.
  3. API Reference — the verified endpoint inventory and data model.
  4. Sources / Flagged for Review — per-row provenance and irregularities.
