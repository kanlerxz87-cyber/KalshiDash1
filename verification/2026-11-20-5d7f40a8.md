## Irregularities flagged for review

1. **Non-official host for contract PDFs.** The repo links contract terms / product certifications to
   `https://kalshi-public-docs-staging.s3.us-east-1.amazonaws.com/regulatory/product-certifications/*.pdf`
   (about 500 occurrences across PRESNOM, PGATOUR, AAAGAS, PRESPERSON). That is a staging S3 bucket name,
   not an address listed in Kalshi's public docs. The same files are also linked at
   `https://assets.kalshi.com/contract_terms/*.pdf` and `https://assets.kalshi.com/regulatory/product-certifications/*.pdf`.
   Recommendation: replace staging links with the `assets.kalshi.com` links, after a manual check that each PDF exists there.
   Not verified in this session (the sandbox cannot reach these hosts).
2. **Live Kalshi API unreachable from the build sandbox.** `curl https://external-api.demo.kalshi.co/trade-api/v2/exchange/status`
   failed with an SSL error (exit 35) and the host is outside the sandbox allowlist. Live values in `data/live/*.json` therefore
   cannot be re-checked here and are not verified by this session.
3. **Newer host migrations not reflected.** `api_environments` lists dedicated user hosts and an external-feeds host,
   and marks `warp-ws` hosts as deprecated. Repo code does not reference these, so anything built on them needs review.
4. **COORDINATION.md is 1,200+ lines** with repeated and out-of-date "current session" headers (several refer to
   branches other than this one). Left unedited beyond this session's own section, to avoid clobbering other sessions' records.
