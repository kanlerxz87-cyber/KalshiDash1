## 3. Reproduced defects and corrections

### Paper execution and canonical performance — F-PAPER-01 / F-PAPER-02

- Old code bought NO at `no_bid_dollars`, used last price when the ask was missing, accepted invalid/fractional quantities and ignored available size. `assets/paper.js` now centralizes the project `observed-ask-v2` rules: buy the side ask only, whole positive count ≤1,000, confirmed sufficient touch quantity, active exchange-confirmed $1 binary contract, exact demo source URL, and local response observation age ≤15 seconds.
- The 15-second age limit is a **project operating rule**, not an exchange guarantee: cached server responses may still lag. No fill is claimed from captured/snapshot data. Strategies share per-observation size consumption and global project caps (50 open positions / $1,000 open entry cost), not a guessed account balance.
- Only finalized binary yes/no results settle. Closed/determined/disputed markets and stored open positions stay in the polling set. Missing exchange settlement time stays blank; local settlement-observed time is distinct. Scalar/unknown results do not become yes/no.
- Mark-to-market uses the purchased side's bid and adequate full-position size; if any open mark is unconfirmed, the whole unrealized total is blank, not a misleading partial sum. Settled arithmetic is revalidated before statistics/equity inclusion.
- Earlier local records are kept as **legacy/unverified**, not recertified after the fact. They are excluded from corrected Portfolio/Trade analysis totals. Gross P&L excludes trading fees, latency, queue position and impact. No validated ROI or actual account profit is claimed.

### Chart and quote provenance — F-CHART-01 / F-OBS-01

- Snapshot prices retain capture timestamps, never page-load time. Chart points are null-safe, sorted/deduplicated, with published candle timestamps preserved. The snapshot axis ends at capture time.
- Corrected equity uses signed dollar bounds, not a binary $0–$1 price clamp, and final settlement/recorded observation times rather than trade-entry time.
- Gold markers identify **actual ≥$0.10 changes in either direction**, not absolute $0.10/$0.90 price levels. Adjacent rows link source observations and the event; verified news causes remain blank/unverified. A line between samples is not evidence of what happened between them.
- Public 1/60-minute candles and timestamped orderbooks refresh while online. Seconds are browser observations, not exchange trade times. Missing or malformed book numbers are not converted into zero-price/zero-count levels.
- Discovery no longer copies an older last price into a newly timestamped response when its new field is missing. Snapshot alert replay skips null closes and does not backfill today's score onto older candles. Exact ten-cent boundaries survive floating-point representation.
- The browser 0–100 research formula is explicitly distinct from the console's 0–1 engine heuristic. Missing touches earn zero tightness; unsized/one-sided/crossed/contradictory touches are ineligible. Volatility uses the actual last interval, not a price compared to itself. Neither formula forecasts returns.
- Public-data access automatically retries after snapshot mode without asking the trader for input.

### Authenticated demo-only safety — F-DEMO-01

- Previously `KALSHI_API_ROOT` could target production/an arbitrary host. The tool now validates the two official HTTPS demo roots **before loading a key or making any request**, refuses credentials/query/extra-port/altered-root forms, and refuses redirects.
- Positive safe whole count and unrounded (≤4 decimal) prices strictly between $0 and $1 are project CLI constraints. The exchange still validates market eligibility, grid/funds and actual execution. Dry-run and confirm flags cannot be combined.
- Failed/empty account reads cannot create `connected:true` or a successful capture timestamp. The captured first-page lists are explicitly not a complete performance history.
- All tests are offline, with generated ephemeral test keys/mock HTTP. The committed `data/account.json` remains disconnected with no capture time. Secret enumeration returned 403, which proves only a permission limitation; secrets are **not** asserted absent. **No authenticated exchange request or order was sent.**

### Source contract, proposals and legacy analysis — F-SOURCE-01 / F-LAB-01

- The former row checker accepted any anchor as an official source and excluded rules/suggestions/process rows. It now requires an approved explicit publisher URL across all canonical static tables, with negative tests for internal links, lookalike domains, HTTP and embedded credentials. GitHub project definitions are clearly not exchange validation.
- Every source/policy/schema/suggestions row links relevant official mechanics or its actual project-author definition. Static market/settlement rows retain their official API sources. Runtime book, jump, ranking, trade and lab rows are checked in DOM tests. Presence/domain checks do not prove semantic correctness or fetch external links.
- The historical five-cell F-16 row lacked its source cell; the six-column table is repaired with an archive provenance link. Historical flag counts/statuses are not rewritten as current observations.
- Suggestions no longer promise an absolute threshold line, guaranteed schedule freshness, provisional-result payout or an expected win rate from candle-only backtesting. Recommendations/impact/effort remain explicitly project judgments.
- Strategy Lab remains an **unverified exploratory legacy** reader. It no longer invents current close time for a settled record with no close timestamp, or zero P&L for a group with no known P&L. Seed/topic/strategy filters affect all summaries and synthesis, not just the visible log. Its source links never pretend a synthetic/seed ticker is a verified exchange fill.
