## How the checks were made

- The build sandbox cannot reach `*.kalshi.co` (`curl` returns `SSL_ERROR_SYSCALL`, re-tested this session). Every check was therefore made with the fetch tool against the official endpoints below.
- All calls are unauthenticated `GET` requests. No keys, no orders, no portfolio calls.
- Large responses are returned in chunks. Only chunk 0 of each series list was read. Chunk counts are given so a reviewer knows how much was not read.
- Reproduce any row with: `curl -s "<URL>" | python3 -m json.tool | head -120` from a machine that can reach the host.

Enums confirmed from the Get Markets OpenAPI in the reference above (read 2026-11-20):

- Request `status` filter: `unopened`, `open`, `paused`, `closed`, `settled`.
- Response `Market.status`: `initialized`, `inactive`, `active`, `closed`, `determined`, `disputed`, `amended`, `finalized`.
- Response `result`: `yes`, `no`, `scalar`, `""` (empty = not yet determined).
- The docs say responses are cached, so prices and status "can lag the exchange by several seconds".

## Irregularities (for the reviewer)

- **F-L4-01 — series volume not reconciled.** `KXDPWORLDTOUR` shows `volume_fp` 8,245,802,181.00 at series level. The three sampled winner markets show `volume_fp` 112,110.67 to 348,906.19 each. The series figure may be cumulative across events, so this is not proven wrong. It has not been reconciled. Source: G1 URLs above.
- **F-L4-02 — quote vs last trade.** `KXSCOTTIESLAM-28` (open) shows `last_price_dollars` 0.5500 while `yes_bid_dollars` is 0.9900 and `yes_ask_dollars` is 1.0000. The docs define `last_price` as the last traded price, so a gap is possible. It is recorded, not explained. Source: G2.
- **F-L4-03 — settlement sources are fragments, not sources.** `KXMAMDANINYC` (E4) declares `settlement_sources` names such as "The Source Agencies are", "in hierarchical order", "or equivalent electoral authority of the relevant …", and "the official religious authority (e", with URLs `https://kalshi.com/`, `https://constitutionalcourt.com`, `http://leader.ir`. These look like sentence fragments from the contract terms. The domains have not been checked and must not be treated as official sources. Source: `GET …/series?category=Elections&include_volume=true&limit=50`, chunk 0.
- **F-L4-04 — series with no markets.** `KXDJTFLOH` ("Trump Florida Ohio") is listed as a series, but `GET …/markets?series_ticker=KXDJTFLOH` returns no markets. Its listed `settlement_sources` point to congress.gov. Source: E2.
- **F-L4-05 — long settlement lag and blank rules (`KXLTCMAXY-25`).** `close_time` is 2025-12-31T15:00:00Z but `settlement_ts` is 2026-11-04T23:12:47Z, about 308 days later. `rules_primary` and `rules_secondary` are empty strings, so the resolution rule cannot be read from the API. Source: C1.
- **F-L4-06 — title typos in the API.** `KXXRPY` is titled "XRP Annual mecnet". `KXRYDERCUP` is titled "Ryder Cup " with a trailing space. These are shown exactly as the API returns them. Source: C3, G4.
- **F-L4-07 — staging host in contract links.** Many series `contract_url` values point to `https://kalshi-public-docs-staging.s3.us-east-1.amazonaws.com/…` (e.g. `KXPGATOPX`, `KXSCOTTIESLAM`, `KXDPWORLDTOUR`, `KXLTCMAXY`). Others point to `https://assets.kalshi.com/regulatory/…`. The staging host should not be linked as a production contract document. Source: series URLs above.
- **F-L4-08 — status vocabulary.** The request filter uses `open`; the response uses `active` (and `inactive`, `finalized`). Both match the official enums above. Dashboards must map them explicitly. Cross-reference: F-19 on the root Flagged page.
