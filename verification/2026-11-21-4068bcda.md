## 2. Defects Fixed in `scripts/fetch_snapshot.mjs` (Task S2)

`session-c144ad6a` recorded an open handoff in `COORDINATION.md` and `verification/2026-11-21-c144ad6a.md`:
> "`scripts/fetch_snapshot.mjs` builds several `/series?…&limit=50` query URLs... `limit=50` is undocumented for that endpoint."

During our line-by-line review of `scripts/fetch_snapshot.mjs` against D-2 (`api_environments`), D-3 (`get-series-list.md`), and D-9 (`quick_start_authenticated_requests`), we verified two issues in `scripts/fetch_snapshot.mjs` and fixed both in commit `d64db2d`:

1. **Removed undocumented `&limit=50` from all 6 `/series` query URLs (`TOPICS[].seriesQueries`):**
   - Before:
     - `/series?category=Economics&tags=Oil%20and%20energy&include_volume=true&limit=50`
     - `/series?category=Economics&limit=50`
     - `/series?category=Elections&include_volume=true&limit=50`
     - `/series?category=Culture&limit=50`
     - `/series?category=Crypto&include_volume=true&limit=50`
     - `/series?category=Sports&tags=Golf&include_volume=true&limit=50`
   - After:
     - `/series?category=Economics&tags=Oil%20and%20energy&include_volume=true`
     - `/series?category=Economics`
     - `/series?category=Elections&include_volume=true`
     - `/series?category=Culture`
     - `/series?category=Crypto&include_volume=true`
     - `/series?category=Sports&tags=Golf&include_volume=true`
   - Source: [Get Series List](https://docs.kalshi.com/api-reference/market/get-series-list.md) (D-3), matching canonical `scripts/fetch-snapshot.mjs`.

2. **Fixed authenticated request signing path in `getAuth(pathname)` (`scripts/fetch_snapshot.mjs:39–55`):**
   - Before: `const signature = sign(key, ts, 'GET', pathname);` where `pathname` was `/portfolio/balance` or `/portfolio/fills?limit=200`. That omitted `/trade-api/v2` and left the `?limit=200` query string attached during signing.
   - After: `const signPath = new URL(API + pathname).pathname; const signature = sign(key, ts, 'GET', signPath);` so the signed message uses `/trade-api/v2/portfolio/balance` and `/trade-api/v2/portfolio/fills` (full path from root, query parameters stripped).
   - Source: [Quick Start: Authenticated Requests](https://docs.kalshi.com/getting_started/quick_start_authenticated_requests) (D-9) and [Request Signing](https://docs.kalshi.com/getting_started/api_environments#request-signing) (D-2), matching `tools/demo_trader.mjs:69–72`.
