## What this confirms or changes

1. **Gas (AAA) series exist in the demo.** Confirmed by V5 and V6. The earlier statement that gas markets were "not located in demo events" is wrong (already flagged as F-15 on the root Flagged page).
2. **The root gas filter misses some AAA gas series.** The root site (`assets/app.js`, `TOPICS.gas`) asks the API for `tags=Oil & Gas` and keeps only tickers starting with `KXAAAGAS`. `AAAGASMAX` (V6) is AAA-settled but has tag `Oil and energy` only, so it is excluded. Flagged as F-17.
3. **Diesel is AAA-settled but is not gasoline.** V5 and V9 show `KXDIESEL*` series with AAA settlement. The site's gas scope excludes them. Scope decision left to the reviewer (F-18).
4. **Culture: the category name is in the series data but not in the tag map.** V3 returns series with `category: "Culture"`. V2 has no `Culture` key. The root Flagged page (F-04) said "Kalshi has no category named Culture". That is now contradicted by V3. F-04 is refined, not closed. Which category is canonical is a reviewer decision.
5. **Status vocabulary.** V9 shows that a `status=open` request returns markets whose `status` field reads `active`. This is consistent with the response enum that the F-03 note already lists. The site's browser code does not compare `market.status` to `"open"` (it requests `status: "open"` as a query parameter), so no visible error is expected. Recorded as F-19 for awareness.
6. **Demo volume is not real-market volume.** V9 and V3 show zero volume on many open series. The demo's own warning (https://docs.kalshi.com/getting_started/demo_env) applies to every price shown.
7. **The `dash/` suite's gas matcher is too broad.** Its snapshot's gas topic lists `SPRMIN` (Strategic Petroleum Reserve) and `KXPAGAS` ("Pennsylvania natural gas production"). The matcher (`dash/js/config.js`: title `/\bgas\b|gasoline|fuel price|SPR\b/i`, ticker `/GAS|SPR/i`) matches both. Flagged as F-20.
