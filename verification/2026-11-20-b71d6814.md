### Reproduce

```bash
python3 - <<'EOF'
import json, collections
from urllib.parse import urlparse
d = json.load(open('data/snapshot.json'))
ents = []
def walk(o):
    if isinstance(o, dict):
        if isinstance(o.get('settlement_sources'), list):
            for s in o['settlement_sources']:
                ents.append((o.get('ticker') or o.get('event_ticker'), s.get('name'), s.get('url')))
        for v in o.values(): walk(v)
    elif isinstance(o, list):
        for v in o: walk(v)
walk(d)
uniq = list(dict.fromkeys(ents))
print(len(ents), len(uniq))
print(collections.Counter(urlparse(u or '').netloc for _, _, u in uniq).most_common(15))
EOF
```

## Limitations

- Each row's settlement sources were checked for classification (publisher vs. search vs. profile vs. exchange vs. placeholder). The audit did not open each publisher's page to confirm it is the authority for each contract. That needs a manual review against each contract's rules (`contract_terms_url`).
- B2 covers four golf rows, not every row on the site.
- The sandbox cannot reach `*.kalshi.co` directly, so live reads used the fetch tool. Reproduce any row with `curl -s "<URL>" | python3 -m json.tool` from a machine that can reach the host.
