Swing catalyst links

Live annotation layer for sharp price moves. When a contract price moves ≥ $0.10 in either direction, the swing is recorded and annotated with events and website links: the official Kalshi endpoints the row came from, the event's official settlement sources (returned by the API itself), and clearly labelled possible-catalyst discovery searches. Discovery links are external news/web searches — they are not evidence of causation, and nothing on this page asserts what caused a move.

Live swing feed (scrolling)

Newest first. Each entry links to the market/event source and possible-catalyst searches. Persisted in this browser (localStorage, key kalshidash:catalyst:swings:v1), capped at 400 records.

Highest-dollar focus-topic markets (watchlist)

Ranked by the derived 24 h dollar-volume estimate volume_24h_fp × last_price_dollars (the API has no dollar-volume field — derived, labelled est.; see flag F-03). Topic classification is a documented client-side heuristic on the API's category/title/series fields; Get Events documents no category parameter, so no server-side category filtering is used or claimed (flag F-62).

Events & official settlement sources

These links come from the API's settlement_sources field on each event (Get Events ↗) — they are exchange-published source strings, not independently verified publishers or inferred causes. Search/social/placeholder URLs are flagged on Flagged for Review.

How swings are detected (methodology)

  • Threshold: |Δ price| ≥ $0.10 between two observations of last_price_dollars (fixed-point dollar strings — Fixed-Point Representation ↗).
  • Observation bases (labelled on every record): live-sample (polled in this browser every 30 s), candle-close (1-min API candle closes, Get Market Candlesticks ↗), 24h-change (the API's previous_price_dollars field, which the official spec defines as the last traded YES price a day ago — a day-over-day comparison, kept separate from intraday swings and never used to corroborate one; see F-90).
  • Cooldown: 3 min per ticker + direction, so one move does not spam the feed.
  • Ranking: watchlist sorted by derived 24 h dollar-volume estimate (labelled; never presented as an official Kalshi figure).
  • Settlement: markets resolve result = yes or no; winning side receives $1 per contract (Market Settlement ↗).
  • Rate limits: unauthenticated public requests are subject to separate limits and the docs say to back off on 429 (Rate Limits ↗). Exact unauthenticated budgets are not published — the client polls conservatively and backs off 60 s on 429/403.
