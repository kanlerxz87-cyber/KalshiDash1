Questions and gaps

What this dashboard knows, what it deliberately does not know, and where to look for each answer. Every "how to find out" line points at an official Kalshi source.

Resolved questions

QuestionAnswerSource
Which endpoints should the dashboard use? REST https://external-api.demo.kalshi.co/trade-api/v2 (recommended) or https://demo-api.kalshi.co/trade-api/v2; WebSocket wss://external-api-ws.demo.kalshi.co/trade-api/ws/v2 or wss://demo-api.kalshi.co/trade-api/ws/v2. Demo environment · API environments
Can the dashboard read market data without an account? Yes. Series, events, markets, order books and candlesticks are public endpoints that need no authentication. Quick Start: Market Data
How does a market resolve, and how is a winner paid? result becomes yes, no or scalar. For a simple $1 binary contract the winning side receives $1.00 after finalized; determined is provisional. Scalar payouts follow their own settlement bounds and are not modeled as yes/no here. Market Settlement · Market Lifecycle
How do I read my demo account? Sign each request: base64(sign(timestamp + METHOD + path)) with RSA-PSS/SHA-256 or Ed25519, and send the KALSHI-ACCESS-KEY, KALSHI-ACCESS-TIMESTAMP and KALSHI-ACCESS-SIGNATURE headers. The path excludes the query string. Quick Start: Authenticated Requests
How do I place an order? POST /portfolio/events/orders with ticker, side (bid or ask), count, price and the remaining order fields. Create Order (V2)
Why is there no live streaming feed? The WebSocket endpoint requires API-key authentication during the handshake, even for public market-data channels. The dashboard therefore polls REST, which is cached briefly by the exchange and can lag a few seconds. WebSocket Connection · Data freshness
Which series count as "gas prices"? The AAA gasoline series (ticker prefix KXAAAGAS, or a title containing "gas price"). Each settles against AAA. Crude-oil and coal series in the broader "Oil and energy" tag are excluded by that rule. Live series query
Can a browser call the demo API directly? Yes for public reads; no for signed requests — measured 2026-11-21, not assumed. The demo host echoes the page origin in Access-Control-Allow-Origin (with allow-credentials: true) on every public endpoint the site uses, so the live tables and charts work from the browser. Its preflight does not allow the KALSHI-ACCESS-KEY / -SIGNATURE / -TIMESTAMP headers, so a portfolio read or an order must run server-side (here: GitHub Actions with repository secrets). A visitor whose network blocks the host still falls back to the committed snapshot, and the pages say so. Raw measured headers · verification record · WHATWG Fetch · Auth headers
Does Kalshi have a "Culture" category? Yes, as a series category. GET /series?category=Culture returns series such as "Will Grok be banned this year". The official tag taxonomy has no Culture entry, which is what caused an earlier page in this repository to claim the category did not exist. Live series query · Live tag taxonomy

Open questions

QuestionWhy it mattersHow to find out
What does a real demo order cost in fees? It changes the expected value of every strategy, so gross paper P&L cannot be treated as a net return or a proven upper bound. Read the fee schedule for your account and the fee_type on the series (Get Series List), then compare one settled paper trade with the matching fill in your demo account.
Which news or event caused a swing? These market-data responses do not establish causation. A published settlement-source string may itself be unverified; it is not evidence of a news catalyst. Open the Kalshi market page for the contract and read the linked settlement source for the underlying at the time of the move, then check the official trade observations. Leave the cause blank until independently verified.
How long do settled markets stay queryable? Older resolutions drop out of the public endpoints, which shortens the back-testable history. Use GET /historical/markets and the historical candlestick route described in Get Markets.
Does the demo exchange have a real order book for the busiest contracts? Empty books make the liquidity view and the depth term of the ROI score unusable for those rows. Call GET /markets/{ticker}/orderbook?depth=20 for the contract and look at orderbook_fp.yes_dollars and orderbook_fp.no_dollars (official book schema). An empty book alone does not prove a market exists.
How often can the dashboard poll without hitting a limit? Polling too fast is throttled; the answer determines the right refresh interval for the alert feed. Read the token-bucket rules in Rate Limits and Tiers and watch the X-RateLimit-* response headers.

Known gaps in this build

  • The committed account snapshot is disconnected with no capture time. This session made no authenticated exchange call or order. Repository-secret configuration could not be enumerated (403); it is unverified, not asserted absent. Signing/safety tests are offline only.
  • Sub-minute price history only exists while a page is open — the REST candle period is 1, 60 or 1440 minutes.
  • The ROI score, the strategies and the swing alerts are this project's own heuristics; each formula is published so it can be checked or replaced.
  • Only the five requested topics are covered; the demo exchange lists many more categories.
