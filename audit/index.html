4. Blocked or not done in this session

  • Portfolio, trades and automated trading: these need a demo API key and a signed request, which this session does not have. Creating credentials would require manual input, which the brief rules out. Nothing was simulated here.
  • Live alerts and the two chat feeds: they need the WebSocket feed, which requires an API key (V11). They are claimed by other sessions on the board.
  • Shared site index and navigation: not changed here. They belong to the final integration session.

5. Reproduce the checks

Run these from any machine with internet access. Each returns the JSON that the table cites.

  • curl https://external-api.demo.kalshi.co/trade-api/v2/exchange/status
  • curl "https://external-api.demo.kalshi.co/trade-api/v2/events?series_ticker=KXAAAGASM&status=settled&with_nested_markets=true"
  • curl https://external-api.demo.kalshi.co/trade-api/v2/search/tags_by_categories
