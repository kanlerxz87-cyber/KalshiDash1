Setup (owner action, ~2 minutes)

  1. Create a demo API key pair: account page or POST /trade-api/v2/api_keys/generate (API Keys ↗).
  2. Add repository secrets KALSHI_KEY_ID and KALSHI_PRIVATE_KEY (Settings → Secrets → Actions).
  3. Run Actions → demo-account → Run workflow (or wait for the 6-hour schedule). The page above fills in automatically.

Without secrets this tool is a no-op. Keys are never stored in the repository or sent anywhere except the official demo API host, and mutating commands require an explicit --confirm-live (full security model).
