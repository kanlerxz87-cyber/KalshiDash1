How resolution tracking works

  1. The dashboard polls open markets in the 5 categories (same ranking as the dashboard).
  2. When a market’s status becomes settled, its result is displayed. If the API returns an empty result for a settled market, the page says so explicitly instead of guessing.
  3. Settled markets older than Kalshi’s historical cutoff move to GET /historical/markets — Historical Data docs. Long-term archiving of resolutions is listed as a suggestion (SUG-04).

Tip: keep this page open — it refreshes live. For a permanent record, export the table (browser print → PDF) or use the Python snapshot tool in tools/kalshi_client.py (see README).
