B. Kalshi demo account (optional)

DEMO NOT CONNECTED

Security: your private key is stored only in this browser’s localStorage and sent only to external-api.demo.kalshi.co as a request signature. It is never committed to GitHub and never sent anywhere else. Requests are signed as timestamp + METHOD + path with RSA-PSS (SHA-256) — official authenticated-request guide. Ed25519 keys are attempted in browsers that support them; otherwise use an RSA key (see Flagged F-02).
