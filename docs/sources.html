Sources & line-by-line verification

Every row below is a claim this site relies on. Status is VERIFIED only when the sentence or field was read from the linked official Kalshi page on 2026-11-20; otherwise the row is UNVERIFIED and the value is left blank in the product (never inferred). See Methodology for how each claim is used, and Flagged for Review for open items.

How to re-check a row: open the source link, compare the wording to the claim column, then confirm the behaviour in the live demo API from your browser (e.g. https://external-api.demo.kalshi.co/trade-api/v2/markets?limit=1&status=open). The build environment used to create this site cannot reach the API directly, so live-response shapes are confirmed by the browser at run time — recorded as F-01.
