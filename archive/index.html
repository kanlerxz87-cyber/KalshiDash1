Executive Summary

Key details you should know before using this dashboard.

Platform

Kalshi Demo Trade API v2

REST API base: https://external-api.demo.kalshi.co/trade-api/v2 (also https://demo-api.kalshi.co/trade-api/v2). WebSocket: wss://external-api-ws.demo.kalshi.co/trade-api/ws/v2.

Source: Kalshi demo API (observed)
Scope

Five topic tracks

Gas prices, elections, culture, crypto, and golf only. Each topic has its own category subpage with a table of live events/markets.

Subpages: all categories
Tracking

Live until resolved

Events are tracked until they resolve. Resolution is shown as Resolved: Yes or Resolved: No (or "unresolved" while live), taken directly from each market's result field.

Field: result on /markets/{ticker}
Graph

Price movement over time

Interactive chart: X axis = time, Y axis = current contract price. Choose graph length (seconds, minutes, hours). Shows current bid/ask liquidity and contract sizes.

Library: Chart.js (CDN)
Portfolio

Demo account performance

Paper-trade tracker for the Kalshi demo account: categorize trades, review performance, and build strategies by trade type. Live order execution requires Kalshi API keys (not stored here).

See: Portfolio page
Data quality

Verified against official sources

Every table row carries a source link to an official Kalshi API endpoint. Values that cannot be confirmed are left blank and flagged. Nothing is inferred.

See: Flagged for Review

How the data is verified

No values are inferred or filled in. Each row links to its official Kalshi API source. Where the demo API has no data for a topic, the topic page says so explicitly and the item is flagged for review.
