Portfolio Performance

Paper-trade tracker for the Kalshi demo account. Add trades below; they are stored in your browser (localStorage) and re-valued against live Kalshi demo market prices. Trades are categorized by topic/type so you can review performance and build strategies by trade type.

Live execution requires API keys. Reading a real demo-account portfolio and placing live orders use authenticated Kalshi trade API endpoints (GET /portfolio, GET /trades, POST /portfolio/orders). No API key is stored or transmitted by this site. The tracker below is a local paper simulator only.
