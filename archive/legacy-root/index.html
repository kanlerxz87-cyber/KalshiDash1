Key findings (short)

  • Public market data (events, series, markets, order books, candlesticks) is readable without credentials. Verified on 2026-11-20 (see Get Market Orderbook ↗ and Get Events ↗).
  • Resolved markets carry result = yes or no and status = finalized (example: KXAAAGASM-26OCT31-2.50 resolved yes, settled US gas price events (live) ↗).
  • The API has no "dollar volume" field. Dollar figures on this site are derived and labelled as such (see flag F-03).
  • No trades have been placed and no portfolio data is available: no demo API key was provided. See F-07.
