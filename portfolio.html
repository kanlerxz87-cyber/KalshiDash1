Portfolio Performance

Track the Kalshi demo account portfolio: balance, positions, trades, and PnL over time. Categorize trades and build strategies by trade type.

Credentials required. Authenticated portfolio endpoints need a demo API key + Ed25519 private-key signature. No credentials were provided or requested, so this page shows the documented structure only.

Authenticated — not connected What portfolio tracking requires

  • A Kalshi demo account with API access configured (demo.kalshi.co).
  • A demo API key (API key ID) and the matching Ed25519 private key for request signing.
  • Each authenticated request signs KALSHI-ACCESS-KEY, KALSHI-ACCESS-SIGNATURE, and KALSHI-ACCESS-TIMESTAMP headers.

Categorize trades & build strategies by trade type

Once connected, each trade can be tagged by category (gas / elections / culture / crypto / golf) and trade type (directional yes / directional no / spread / hedge). Strategy analysis then compares win rate and PnL per category and trade type.

Trade typeWhat it meansSuggested strategy lens
Directional YESBought YES contracts expecting event to resolve yes.Track win rate & average $ per category.
Directional NOBought NO contracts (or sold YES) expecting event to resolve no.Track win rate & average $ per category.
Spread / hedgeOffsetting YES and NO positions across related events.Track net exposure per category.
Scalp / swingShort-term price-movement trades, not held to settlement.Track hold time & per-trade $.
Source: order lifecycle — Quick Start: Create your first order (place, amend, cancel orders); Market Settlement (how positions resolve yes/no).
