What is needed to switch this on

  1. A demo API key pair. Keys are created on the account page or with POST /trade-api/v2/api_keys/generate (API Keys ↗).
  2. Signing must happen server-side. A static page cannot hold a private key safely. See suggestion S-02 on the Suggestions page.
  3. Rate-limit handling: the balance endpoint has its own bucket, one call per second on Basic and Advanced tiers (Rate Limits and Tiers ↗).
