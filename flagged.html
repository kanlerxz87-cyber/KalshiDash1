F-49Irregularity (upstream demo data)The demo API returns prices that contradict each other. One sampled row for KXPRESPERSON-28-GABB came back with last_price_dollars: "0.8030" and yes_ask_dollars: "0.8030" while no_bid_dollars was 0.9970. A binary book must satisfy yes ask + no bid = $1.00 (Orderbook Responses), so that row is impossible: taken at face value it is a fake $0.80 crash from $0.003. Reading the same market directly returned the healthy book yes 0.0020/0.0030, no 0.9970/0.9980, previous price 0.0030. A second case: KXBTCY-27JAN0100-B47500 reported last price 0.98 against a 0.05/0.06 book. The alert engine therefore validates every row against reciprocity, rejects a stale last price on a tight book, and publishes a sampled alert only when the new price is corroborated by a second published field; anything else is suppressed and counted.
