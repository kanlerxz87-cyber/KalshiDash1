Strategy lab

Categorise every simulated trade recorded in this browser, analyse performance by strategy, topic, entry-price band and holding period, and synthesise strategy rules from the type of trade that actually won. All data is simulated — no orders are placed, no credentials are used, and every computed metric is labelled. Values that are not recorded stay blank.

Strategy synthesis (from the type of trade)

Rule hypotheses are generated from cells of the categorised trade log where at least 3 settled trades show ≥ 60% wins and positive average P&L. They are hypotheses from simulated data — not verified performance, not financial advice.

Published trade schema — kalshidash:trades:v2

Auto-trade engines and manual simulators can write records in this shape to the localStorage key kalshidash:trades:v2 (array of records, or {"schema":"kalshidash:trades:v2","trades":[…]}) and this page will ingest them automatically. Field names follow the official API spelling (*_fp quantities, *_dollars prices — Fixed-Point Representation ↗). Blanks are allowed and are never filled in.

Method & limits (read before using any number)

  • Simulation only. Real order placement is POST /portfolio/events/orders with signed auth headers (Create Order (V2) ↗); this site never calls it. Tracking a real demo account needs the account holder's API key, which is deliberately not requested or stored (see Questions & answers).
  • Settlement semantics used for computed P&L: winning side receives $1 per contract; result = yes/no (Market Settlement ↗).
  • Recorded vs computed. Where both exist and differ by more than $0.02 the row is flagged — differences are reported, never silently reconciled.
  • Seeded rows (marked seed) are pre-loaded examples from the dash/ suite store; exclude them with the filter above for clean analysis.
  • Synthesis is descriptive, not predictive. Rule hypotheses are generated from small simulated samples; demo prices may not reflect real markets (demo env ↗). No backtest returns are claimed anywhere on this page.
